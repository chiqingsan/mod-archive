# AquaSense 正式版适配

针对本机 Probably Stolen 正式版 Mono 程序集构建，使用游戏内置 ModLoader 和配置界面。构建：`dotnet build -c Release`；将 `manifest.xml` 和生成的 `AquaSense.dll` 放进游戏 `Mods/AquaSense` 文件夹，然后在游戏的模组界面启用。

AquaSense 会在水容器 Tooltip 中显示水质纯度、液体成分、滤芯名称和耐久；倒水或转移液体后更新标签；滤芯耗尽时从玩家库存和嵌套容器中寻找可用滤芯并自动更换；韧棉织物（`kotton_fabric`）耗尽时，也会自动换上一块有耐久的韧棉织物（默认开启，可单独关闭）。液体成分默认以对齐的彩色进度条视图显示（名称+数量 / 进度条 / 百分比），可在设置中关闭并切回纯文本列表；可设置过滤器最低耐久度，低于该值的过滤器不参与自动更换。水质扫描、标签更新、耐久显示、自动换芯、织物自动换新、耐久度门槛和成分进度条都可以单独开关。

试玩版的 MelonLoader 设置不会自动迁移；请在游戏模组设置中重新设置。自动换芯会修改库存，首次验证前请备份存档。

## v1.12.0

- 新增「显示水质详情」设置（默认开启）：关闭后，水容器的物品详情里不再显示水质详情标题与成分行（滤芯耐久等其它行不受影响），只读成分数据接口同时返回空。
- 阴沟水（沟渠水）及纯度更低的未知水，文字颜色统一改为警示红 #C73E3A。
## v1.11.2

- 水质标签高亮改为**只给文字上色**，去掉底色（设置项文案同步为「给水质标签添加文字颜色」）。原因：游戏富文本的背景层按独立 TMP 节点排版，和前景字形对不上；自绘背景块虽然位置能对上，但宽度仍会漂移。按最小性能/稳定优先，不再做底色，也不再为它多画任何 UI 对象。

## v1.11.1

- 尝试修复水质标签底色错位：改为在文字下层自绘背景块，按渲染后的字形坐标定位；实测仍有偏移，已被 v1.11.2 替换。

## v1.11.0

新增两个默认开启的水质标签显示设置，均可在模组设置中单独关闭：

- **给水质标签添加文字颜色**：按水质品质（纯水 / 优质水 / 普通水 / 幽灵水 / 锈水 / 阴沟水，对应游戏扫描仪面板的 6 档）给「水质详情」标题里的品质名单独着色，游戏自带的 `[标签] xxx水` 行也按同一品质配色。文字色使用游戏富文本的前景色，不插入额外标记字符，换行位置与列宽不受影响。
- **成分按占比从高到低排序**：成分行按占比降序排列（相同占比保持液体定义顺序），进度条模式与纯文本模式都生效。只读成分数据接口 `aquasense.composition.v1` 返回的行顺序与面板一致。

## v1.10.2

新增只读成分数据接口：`AppDomain` 槽位 `aquasense.composition.v1`（函数返回每行成分的名称、体积文本、百分比文本、比值与条色）和版本槽位 `aquasense.composition.version.v1`。其他模组无需引用 `AquaSense.dll` 即可读取水容器成分，便于《物品详情美化》等模组在自己的排版中展示或绘制原生进度条；AquaSense 现有面板渲染保持不变。接口说明与示例见 `API.md`。

## v1.10.1

成分进度条改为默认开启；已保存的开关设置仍然优先，不强制覆盖用户选择。

修复成分进度条显示成 sprite 标签或完全不显示的问题：底轨和填充改用 Unity 原生 Image 矩形，隐藏的 TMP link 只提供每行完成排版后的坐标。进度条跟随详情面板的缩放、裁剪与隐藏；复用面板、切换为普通物品或关闭进度条时清理旧显示。无需额外图片资源。离线测试覆盖矩形创建、比例、位置更新、复用与关闭清理；游戏内视觉效果仍需实测。

## v1.10.0

新增“耐久度以下的过滤器不参与更换”设置：默认关闭；开启后可在 0–600 的滑块中选择最低耐久度（默认 200），自动换芯只会换上耐久度不低于该值的过滤器，低于该值的候选会被跳过并继续比较下一个（韧棉织物自动更换同样适用）。

美化水质详情中的成分列表：开启后成分按“名称: 数量 / 进度条 / 百分比”三列对齐；进度条同时显示彩色填充段和深灰色未填充轨道，能直接看出每种成分已占与未占的比例。列宽按游戏内字体的实际像素宽度测量，使用绝对列位置统一进度条起点和百分比右边界。进度条固定总宽，使用原生 UI 矩形绘制彩色填充和灰紫色底轨。新增“用彩色进度条显示成分占比”设置；关闭时保持纯文本列表。

占比四舍五入后为 0.00% 的成分在进度条模式下也会显示：进度条按实际占比绘制（非零成分至少显示半个逻辑像素；不足 100% 时至少保留半个逻辑像素底轨），百分比标为 `‹0.01%`（纯文本模式在该成分被显示时也这样标注，避免读成 0.00%）；纯文本模式下仍由“隐藏四舍五入后为 0.00% 的成分”设置决定是否显示。低于 0.1 ml 的体积极小成分改用整微升显示（如 3 微升显示为 `3 uL`，与游戏扫描仪面板的写法一致），不会显示成 `0 ml`，也不会出现 `0.003 ml` 这类难读的小数。正常长度的名称（含中文）会完整显示，只有异常长的名称才会被截断并加省略号，保证各列始终对齐。

设置面板中的“最低耐久度”滑条会实时显示当前数值（从主菜单打开设置面板也可见）。该数值显示的补丁在主菜单界面就绪后立即安装；自动换芯等主体功能仍按原设计在进入店铺后安装，避免启动阶段与其他模组发生初始化冲突。

## v1.9.1

新增“隐藏四舍五入后为 0.00% 的成分”设置，默认开启。关闭后会显示全部液体成分，包括占比四舍五入后为 0.00% 的成分。

## v1.9.0

新增“韧棉织物耗尽后自动更换”设置，默认开启。水容器里的韧棉织物（`kotton_fabric`）耐久耗尽后，会从玩家库存和嵌套容器中寻找另一块有耐久的韧棉织物换上；只做织物换织物，不会消耗细滤芯，也不影响 v1.8 的滤芯自动更换逻辑，可在模组设置中单独关闭。

## v1.8.1

自动换芯会跳过循环水养殖系统（RAS）机器槽位里的滤芯，不再把鱼池正在使用的滤水器当作备用换走，也不会替换鱼池里已耗尽的滤芯。

## v1.8

滤芯识别改用游戏的 `WATER_FILTER` 标记：水培芦苇滤芯现在会显示耐久，耗尽后也会作为自动换芯候选；过滤孔过粗的韧棉织物（`kotton_fabric`，只服务化学玩法的大颗粒过滤）仍会显示耐久，但不参与自动换芯。

## v1.5

新增“无需水质扫描仪查看液体成分”设置，默认关闭。开启后无需持有扫描仪即可在水容器悬停面板查看液体成分和水质详情；自动更新标签仍要求拥有扫描仪。滤芯耐久显示独立于此设置。
