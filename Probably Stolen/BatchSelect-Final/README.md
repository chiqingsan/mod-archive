# 按键拖拽多选框

《深空当铺 / Probably Stolen》0.46D 模组。

## 功能

原版可以从容器空白处拖动鼠标拉出批量选择框，但**起点必须是没有物品的空位**——容器装满物品时就没法框选。

装上本模组后：**按住触发键（默认空格）再拖动鼠标，可以从任意位置拉出批量选择框**，包括直接按在已有物品的格子上开始拖。

- 不按触发键时，原版行为完全不变（仍然只能从空位开始框选）。
- 按住触发键时，左键点击不再会打开/激活/拖动物品，松手后也不会误触单击交互。
- 触发键可在 **游戏设置 → 按键 → 修改触发拖拽的快捷键** 中修改。

## 安装

把 `BatchSelect.dll`、`manifest.xml` 一起放进：

```
<游戏目录>\Mods\BatchSelect\
```

（`preview.png` 可选，用于模组列表预览图。）

## 说明

- 默认触发键是空格，和原版「对话推进」键相同。两者不会互相干扰（对话中不会有物品框选），但如果你在设置里想把触发键改回空格，而「对话推进」仍是空格，游戏会提示按键冲突——先把对话推进键改成别的即可。
- 模组设置里还有一个「触发键（备份）」文本项，那是手动/异常情况下的备份存储；正常改键请用游戏设置里的按键项。
- 需要游戏自带的 Mono ModLoader（本作正式版内置），不需要 MelonLoader。

## 实现

- Harmony patch `ItemMultiSelectHandler.OnEventPress`：按住触发键 + 左键、且鼠标起点压在物品上时，手动把原版处理器置入「待框选」状态（原版只在起点无物品时才会进入该状态）。
- Harmony patch 四个会在同一帧处理左键按下的处理器（`ItemMouseDragHandler` / `ItemMouseDoubleClickHandler` / `ItemDefaultActivateHandler` / `ItemSelectHandler`），按住触发键时跳过它们，避免拖动物品或触发单击/双击交互。
- patch `GameOptionRegistry.EnsureVanilla`，把触发键选项追加到游戏原生按键设置里；触发键值保存在模组配置文件中。

不开启新线程、不做每帧扫描；仅在按键按下时介入。
