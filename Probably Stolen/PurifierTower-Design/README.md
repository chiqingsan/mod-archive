# PurifierTower-Design — 净水塔设计（正式版 Probably Stolen）

> 一台 3×3 的店铺机器：玩家把自己的**原版净水器**放进塔里，塔自动完成「补水 → 净水器自己净化 → 检查达标 → 存入 600L → 打印灌装」。
> 当前交付：**设计文档 v0.8** + **UI 原型 v0.3.x**（未写实现）。

## 先看这里（3 分钟版）

**游戏里净水到底和什么有关？**

| 装置 | 作用 | 能不能提高水质档位 |
|---|---|---|
| **电动净水器** `water_purifier` | 每夜按体积预算移除杂质；纯度上限由品质模块决定 | ✅ **唯一手段**（默认上限 99.00%） |
| **滤芯** `water_filter`/`water_filter_adv`（孔径 22） | 液体*转移*时截留大颗粒（有机物/微塑料/矿物…） | ❌ 不滤微生物、不滤重金属/化学物、耗耐久 |
| **水培芦苇滤芯** `hydroreed_filter`（22） | 同上，耐久 200 | ❌ |
| **韧棉织物** `kotton_fabric`（150） | 只拦超大颗粒，基本没用 | ❌ |
| **紫外线灯** `uv_filter` | 点击容器：微生物全灭 | ❌ 不耗耐久也不耗电，但只杀微生物 |
| **净水片** `water_tablet` | 氯化学：化学污染物压到 0.7% 地板 + 杀菌 | ❌ 不除重金属/矿物、破不了上限 |
| **便携净水器** `portable_water_purifier` | 一次性抬到 98.00% | ❌ 到基础档封顶 |

**结论**：紫外线灯=杀菌、过滤嘴=截大颗粒、净水片=化学地板，都只是辅助；**水质档位只由净水器决定**。所以净水塔 = 把「玩家净水器 + 补水 + 达标检查 + 打印灌装」串成自动线，不改净化公式。

**售价**：基础价恒 40 信用点/L（与纯度无关），成交价按水质档乘算——纯水 +100%（≈80/L）、优质 +50%、基础 0%、幽灵 −33%、锈 −75%、沟渠 −90%。

## v0.8 一句话流程

```
玩家容器（手动倒进塔）
        ▼
待处理区 100L（固定容器）
        │ 补水（单一水源）：容器空时补一次——待处理水 → 水龙头（默认关，打开且已解锁）→ 都没有就不动；不混水、不补满
        ▼
净水器区 20×19（玩家放任意台原版净水器；每台自带电池，游戏每夜让它自己净化）
        │ 塔在夜结收尾时：检查每台净水器瓶槽里的水
        │ 达标（≥ 目标档）→ 转移到已处理区
        ▼
已处理区 600L（固定容器，只进达标水）
        ├─ 按钮灌装：1L/3L/6L/20L/60L（打印瓶 + 装水，扣电池区电）
        └─ 空容器点塔：直接从 600L 灌满（不打印、不耗电）
        ▼
输出区（玩家自取，自行议价出售）
```

- **净化完全由玩家净水器执行、自己供电**：塔不代跑净化、不供电、不改数值；塔只做自动化接线（补水、查达标、抽水、UV）。
- **净水器区 20×19 格**：只放净水器；待处理区 100L、已处理区 600L、电池区 4×4 是各自独立区域；输出区 4×7。
- **UV 槽**（净水箱内独立槽）：每次给净水器容器注水后自动 `OnUVUsed` 一次。
- **电池区 4×4**（16 格）：合并电量池，只供塔的打印灌装（净化电由每台净水器的电池槽自理）；也可放**能量列阵 `powerblock`**，每夜给相邻电池 +2 电（商业电力升级后 +4）。
- **定价按原版倍率、不额外加权**：水价与净水器效率都没改，60L 与 30 个 2L 瓶等价；大瓶只省操作，成本仍是净化时间与电。
- **目标档塔统一设置**：普通 9800 / 优质 9900（默认）/ 纯水 9990（需每台净水器品质加成 ≥100）。
- **半瓶也灌**：600L 有多少装多少（按实际装水量计价扣电），输出瓶可之后再补满；但**最少 10ml**，不足则按钮置灰。
- **净水器瓶槽容器玩家自备**：玩家自己往每台净水器的瓶槽放液体容器；没放容器/没电池的净水器不参与。
- **塔内可直接配置净水器**：双击塔里的净水器即打开它自己的窗口（放电池/容器/模块），不用取出重放。
- **600L 满时全停**：转运和补水一起停，UI 提示「已满，请灌装/取水」。
- **水龙头开关默认关**；**单一水源**：容器空时才补一次水（待处理优先、不够不补满，水龙头只在待处理空且开关打开时用），避免混水。
- **纯水不可达的净水器只打按键高亮标记**（参考 QuickSell 高亮实现），不弹提示；净化到极限后本就不耗电。
- **便携净水器可放入但不生效**；净水器台数不设上限。
- **外部交互只和 600L 储水区**：空容器点塔灌满；往待处理 100L 倒水需打开塔窗口后操作。
- 灌装后玩家自己处理，**塔不做自动售卖**；净水器没电池时塔不做提示（停摆即可）。
- **不再要求 0 Harmony**：反射/注入随意（注册、上架、夜结都可用补丁）。

## 关键数值速查

- 净化预算 = `(min(体积,10L)×3‰ + 25ml) × dirtBonus × 1.25`，dirtBonus 按纯度 1→20 插值
- 纯度上限 = `10000 − round(100 × purityMult)`：默认 **9900**；品质加成 ≥100 → **9990**；≥200 → 10000
- 净水器耗电 4/夜/台（它自己的电池）；塔内接水/UV/转运 0 电；打印灌装 = `round(3+0.004×ml)`（1L=7、3L=15、6L=27、20L=83、60L=243）
- 6L 一批：水龙头水（约 8500）→ 优质档约 4–6 夜；沟渠水（3500）→ 约 9–10 夜
- 单瓶价值（优质）：3L≈205、6L≈375、20L≈1550、60L≈3950 信用点（按原版条件倍率推算）
- 60L 与分装等价：60L 优质 = 60×60 + `water_tank` 底价 350 ≈ 3950；30 个 2L 瓶 ≈ 3870（水价与净水器效率未改，定价按原版倍率）
- 能量列阵 `powerblock` 放电池区：每夜给相邻电池 +2 电（商业电力升级 +4），停电事件时停止
