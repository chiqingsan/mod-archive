# QuickSell — 快捷补货

适用于《Probably Stolen》正式版内置模组系统。

1. 顾客购买商品时，平板底部显示等宽的「一键上货」与原版出售按钮，中间间隔 16 UI 单位。
2. 左键「一键上货」摆货；右键打开设置。未指定来源时首次上货会打开设置。
3. 打开要供货的容器，在设置中点击「刷新容器列表」，再点击「加入」。已选择的容器可点击「移除」，选择按存档保存。
4. 可以切换「检索内层容器」（默认开）和「每种保留一件」（默认关；要求多样性的顾客不受此限制）。
5. 运行中按钮显示「取消上货」，再次左键取消后续操作；已经摆上的商品保留。检查后点击右侧原版按钮手动成交。

固定物品和固定容器的内容不参与自动上货。供货区内的储物容器只提取内容；机器内部槽位不自动搜索。柜台已有商品占用预算；无限预算顾客不自动补货。逐件复核实际价格，空间不足或游戏拒绝时跳过；超预算时尝试放回原容器，无法放回则停止并提示。

本版为交互原型，参考 QuickTrade 的行为，使用正式版接口独立实现。尚未包含最优预算组合、自动拆堆、超预算抹零、快捷键、高亮和撤回上货。不会自动确认出售。普通收货界面增加双按钮，捐赠和其他交易模式保留原布局。

库存扫描按约 1 ms 的协作预算分帧，候选最多每帧处理一件；没有后台全库存轮询。原版单次库存快照、容器解析与搬运调用不可被中断，实际耗时仍需实机测量。

已通过编译，尚未在游戏中验证界面与交互。首次使用前请备份存档，并先用低价值物品测试。
