# 帮我上货! (更好的交易体验)

英文名：QuickSell。版本：1.3.4。

适用于《Probably Stolen》正式版内置模组系统。

1. 在存档内，右键平板「一键上货」打开设置；没有顾客时可在原版 Mod 设置中勾选「打开交易助手」（一次性打开请求，自动复位）。
2. 「供货区」页分帧扫描自有储物容器，无需先打开箱子。点击「加入／移除」，记录按存档和周目保存。分页显示容器与所在路径。
3. 自有物品右键菜单新增「保护」，已保护时显示「解保」；「物品保护」页仍可管理台面与已有保护。一个堆叠视为一项，不按商品类型批量保护；移回仓库仍受保护。
4. 「显示提示」页绑定按住查看键，三项文案为「顾客需求物品」「赃物」「违禁物」。默认按住 Ctrl+Q；已有自定义绑定保留，左右 Ctrl 均可触发。支持单键／修饰键组合，Esc 取消，Delete/Backspace 清除。只标记可见物品，松键或失焦隐藏，输入文字和设置打开时不显示。
5. 「选货规则」页选择尽量用满预算／优先腾空间、超预算关／5／10／20、内层容器检索、按需拆堆。
6. 平板底部直接复用原版购买／批发双按钮的位置、尺寸与间距。左键上货，右键设置；运行中左键取消，已搬商品保留。右侧继续通过原版逻辑手动成交。结果用原版通知显示，并保留在上货按钮悬停详情中。

保护、固定物品及其内容不自动上货。供货区内的储物容器只提取内容，机器工作槽位不搜索。柜台已有商品占用预算，无限预算顾客不自动上货。搬运前后复核实际报价、空间及顾客规则；失败尽量放回原容器，无法放回则停止并提示，不删除物品。

任何出售包含受保护物品时均弹一次确认，包括单件出售；超预算说明合并到同一个弹窗。取消不出售；确认并真正售出后删除相应保护记录。确认期间台面、数量、报价、预算或保护状态改变，原确认失效。

三个可替换任务共享约 1 ms 主线程协作预算，不为每个物品创建协程。扫描每库存快照一次，组合计算最多 1024 状态／200000 次转移，实际搬运最多每帧一次。没有后台全库存轮询；原版快照、深层判定和搬运调用不可中断，实际耗时仍需实机测量。

操作栏独立于原版会被清空的按钮容器并复用；设置使用独立尺寸、原版描边与纸色／字体／按钮，不继承平板缩小倍率。布尔开关使用原版勾选框与「已开启／已关闭」状态文字，只更新自身，不重建页面。布局、无闪动、保护成交与高亮的真实效果仍需游戏内验收。整体美化方案先出预览，审阅通过后再实施。

1.3.2 修正设置窗口的实色背景；移除挤在按钮上方的状态文字。高亮以旋转后的占格边界定位，赃物／违禁品角标统一为 7 UI 单位。按住查看时，容器汇总自身与内部物品的提示，关闭容器内部不直接绘制标记；单次遍历复用库存快照及子树结果。

1.3.4 接入用户选定的三张高亮图片：需求四角框、第一版赃物标签、第二版违禁物警告。图片内嵌 DLL，启用时一次解码并打包为最大 512×512 的共享图集，随后释放源纹理与图集 CPU 像素副本。四角独立贴合占格边界，两个角标保持比例并统一最大尺寸；不随物品旋转，不增加子级图标控件。关闭模组释放图集。素材路径为 `Assets/Highlights/`。本轮不实施设置页面的美化预览。

## 限制与验证

- 参考 QuickTrade 行为，正式版代码独立实现。预算组合为有界近似，不保证数学最优；空间不足时可能无法填满预算。
- 拆堆仅限无特征、无内部窗口、无购入成本元数据，且通过原版数量回调与线性报价检查的商品。其他特殊堆叠只整叠上货；未实机验证的物品不宣称支持。
- 不自动成交或抹零，不自动撤回整次上货，不增加供货区库存菜单，不上传工坊。
- 编译与 12 项检查通过，包括 11 项选货逻辑检查（100 个小样本穷举对照与 100／1000／10000 候选计算上限）以及原版占格旋转合同。不能替代 Unity 内的交互、GC 与帧耗时验证。
- 设计、开发顺序和验收清单见 [DESIGN.md](DESIGN.md)。首次成交建议使用低价值物品并保留存档备份。
