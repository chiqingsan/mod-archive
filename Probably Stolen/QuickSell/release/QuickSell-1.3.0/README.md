# QuickSell 1.3.0 — 交易助手

适用于《Probably Stolen》正式版内置模组系统。

1. 在存档内，右键平板「一键上货」打开设置；没有顾客时可在原版 Mod 设置中勾选「打开交易助手」（一次性打开请求，自动复位）。
2. 「供货区」页分帧扫描自有储物容器，无需先打开箱子。点击「加入／移除」，记录按存档和周目保存。分页显示容器与所在路径。
3. 「物品保护」页可保护台面上的具体物品，或取消已有保护。一个堆叠视为一项，不按商品类型批量保护；移回仓库仍受保护。
4. 「显示提示」页绑定按住查看键，分别开关需求、赃物和违禁品。默认未绑定；支持单键／修饰键组合，Esc 取消，Delete/Backspace 清除。只标记可见物品，松键或失焦隐藏，输入文字和设置打开时不显示。
5. 「选货规则」页选择尽量用满预算／优先腾空间、超预算关／5／10／20、内层容器检索、按需拆堆。
6. 平板底部两个等宽按钮，间隔 16 UI 单位。左键上货，右键设置；运行中左键取消，已搬商品保留。右侧继续通过原版逻辑手动成交。

保护、固定物品及其内容不自动上货。供货区内的储物容器只提取内容，机器工作槽位不搜索。柜台已有商品占用预算，无限预算顾客不自动上货。搬运前后复核实际报价、空间及顾客规则；失败尽量放回原容器，无法放回则停止并提示，不删除物品。

批量交易包含受保护物品时弹一次确认，超预算说明合并到同一个弹窗。单件出售不增加保护确认；真正售出后删除相应保护记录。确认期间台面、数量、报价、预算或保护状态改变，原确认失效。

三个可替换任务共享约 1 ms 主线程协作预算，不为每个物品创建协程。扫描每库存快照一次，组合计算最多 1024 状态／200000 次转移，实际搬运最多每帧一次。没有后台全库存轮询；原版快照、深层判定和搬运调用不可中断，实际耗时仍需实机测量。

操作栏独立于原版会被清空的按钮容器并复用；设置使用独立尺寸、原版描边与纸色／字体／按钮，不继承平板缩小倍率。开关只更新自身，不重建页面。布局、无闪动、保护成交与高亮的真实效果仍需游戏内验收。

## 限制与验证

- 参考 QuickTrade 行为，正式版代码独立实现。预算组合为有界近似，不保证数学最优；空间不足时可能无法填满预算。
- 拆堆仅限无特征、无内部窗口、无购入成本元数据，且通过原版数量回调与线性报价检查的商品。其他特殊堆叠只整叠上货；未实机验证的物品不宣称支持。
- 不自动成交或抹零，不自动撤回整次上货，不增加库存菜单，不上传工坊。
- 编译与 11 项纯选货逻辑检查通过，包括 100 个小样本穷举对照与 100／1000／10000 候选计算上限检查。不能替代 Unity 内的交互、GC 与帧耗时验证。
- 设计、开发顺序和验收清单见 [DESIGN.md](DESIGN.md)。首次成交建议使用低价值物品并保留存档备份。
