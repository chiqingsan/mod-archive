日期：2026-10-30。范围为 QuickSell 源码、正式版 0.46D 的内置 ModLoader 合同、本机配置与发布内容；不改动其他模组，不执行工坊上传。

## 性能观察

以下为同一控制台压力样本的一次前后测量，预算为 900，候选价格按固定序列生成。分配量为 `GC.GetAllocatedBytesForCurrentThread` 的差值，不是 Unity 峰值内存或单帧 GC。

| 候选数量 | 调整前分配 | 调整后分配 |
| --- | ---: | ---: |
| 100 | 4360 KiB | 2230 KiB |
| 1000 | 13526 KiB | 3601 KiB |
| 10000 | 13878 KiB | 3952 KiB |

- 固定压力样本增加 8 MiB 分配回归上限；18 项检查通过。该阈值只约束这些样本，不是任意库存的内存保证。
- 三个可替换任务共享约 1 ms 的主线程协作预算，候选计算最多 1024 状态／200000 次转移，实际搬运最多每帧一次。
- 快捷键解析仅配置变化时执行，输入委托缓存；闲置时不扫描库存。高亮只在按住时工作，拖拽每帧仅维护当前一件物品的边界。
- 三张提示图启用时加载一次，合并为最大 512×512 的共享图集，释放源纹理与图集 CPU 副本；每个标记最多六个矩形面。
- 原版列表快照、深层特征判断、空间查询和搬运调用不可中断；约 1 ms 不是严格帧耗时上限。大库存原生快照、特殊堆叠创建和高亮重新遍历仍可能产生开销。
- 本轮不重写选货算法或加入长期索引，避免收尾阶段改变用户刚完成测试的选货行为。

## 注入与行为边界

- 不修改游戏 DLL；不使用 Transpiler、原生函数地址替换或后台线程读取 Unity 对象。
- Prefix 仅在自己的保护确认／上货状态或自己的右键按钮被操作时拦截；一般状态下保留原版路径。Postfix 的模组实例为空时不执行。
- 原版 `Validate` 仅为转发入口，不在其上安装补丁；高亮状态通知使用 `ValidateSelect`。保留原版交易、报价、预算、所有权和库存接收调用。
- 正式版 ModLoader 在 `OnEnable` 前统一注入，并在调用 `OnDisable` 后解除自己的 owner；清理逻辑不解除其他模组补丁。
- 反射访问为私有平板重建签名及启用时的公开父子关系探测，不在逐帧输入路径反射查找。`reflection-external` 声明保留。
- 右键菜单扩展依赖原版单列七按钮结构；第三方改写同一菜单可能不兼容。自定义容器必须使用可发现的原版库存结构，不能承诺所有模组都支持。
- 自动上货按库存实例复核保护与报价。原版／其他模组异常导致不一致时停止并报告；不承诺任意异常都能自动回滚。特殊堆叠仅在已有保守校验通过时拆分。
