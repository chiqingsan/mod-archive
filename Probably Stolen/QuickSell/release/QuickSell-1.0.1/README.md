# 帮我上货! (更好的交易体验)

英文名：QuickSell · 版本：1.0.1

指定供货容器，一键将符合顾客需求和预算的商品摆上柜台。搭配物品保护和按住高亮，减少找货、搬货和误卖操作，出售仍由你确认。

![封面](preview.png)

## 主要功能

- **一键上货**：按当前顾客需求、预算和选货规则，从供货区挑选商品并搬到台面；再次点击可取消，已上货商品保留。
- **供货区管理**：扫描自有容器，无需逐个打开。列表显示库存位置、行列和容器路径，同名容器也能区分；记录按存档、周目隔离。
- **物品保护**：右键物品选择「保护／解保」，也可在面板中管理。受保护物品不参与自动上货；手动出售时，单件、批量均需确认。实际售出后自动清除相应保护记录。
- **按住高亮**：显示顾客需求物品、赃物、违禁物，可分别开关。容器汇总内部提示，拖拽预览跟随标记；松开按键立即隐藏。
- **选货规则**：支持「尽量用满预算／优先腾空间」、内层容器检索，以及通过状态和报价校验的按需拆堆。允许超预算金额可选 0／5／10／20，0 表示关闭。

## 快速开始

1. 进入存档，按 **Ctrl+L** 打开交易助手。
2. 在「供货区」点击「加入」，指定允许提货的容器。
3. 顾客到店后，左键点击平板上的 **一键上货**。
4. 检查台面商品，再点击原版出售按钮成交。

| 操作 | 默认方式 |
| --- | --- |
| 打开／关闭交易助手 | 按一次 Ctrl+L，无需顾客 |
| 显示物品高亮 | 按住 N，松开隐藏 |
| 从交易平板打开设置 | 右键「一键上货」 |
| 保护／解除保护 | 物品右键菜单「保护／解保」 |

面板和高亮快捷键可在「高亮物品」页分别修改，支持单键或修饰键组合；绑定时 Esc 取消，Delete／Backspace 清除。输入文字、绑定按键及游戏失焦时不响应快捷键。也可在原版 Mod 设置中修改配置。

## 使用说明

- 保护按物品实例管理，一个堆叠视为一项；不会自动保护同种的其他物品。固定物品及受保护容器中的物品也不会自动上货。
- 台面已有商品计入预算。台面空间不足时可能无法继续上货，整理后可再次操作；不会自动整理台面。
- 仅负责上货，不自动出售。超预算部分是否抹零，由玩家确认。
- 选货采用有计算上限的近似方案，不保证最优组合或完全用满预算。特殊堆叠无法确认状态与报价时仅按整叠处理。
- 使用按需分帧任务，闲置时不扫描库存。单次原版库存、报价或搬运调用无法中断，超大库存仍可能耗时。
- 当前正式版 0.46D 已有用户实机测试。第三方自定义容器或修改交易、右键菜单的 Mod 仍需单独验证。

## 安装与更新

适用于游戏正式版内置 ModLoader，无需另装 MelonLoader／BepInEx。

将发布包内容放入游戏目录的 `Mods/QuickSell/`，确认其中直接包含 `manifest.xml`、`QuickSell.dll` 和 `preview.png`，然后在游戏内启用模组。

已有测试版用户可在退出游戏后覆盖同一目录。模组 ID 保持 `chiqingsan.QuickSell`，供货区、保护记录及自定义快捷键沿用现有配置。
