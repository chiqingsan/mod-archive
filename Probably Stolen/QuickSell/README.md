# QuickSell — 快捷补货

适用于《Probably Stolen》正式版内置模组系统。

打开顾客平板，点击平板右侧的「快捷补货」。打开要供货的容器，在窗口中点击「刷新容器列表」，再点击容器旁的「加入」。已选择的容器可以点击「移除」，选择按存档保存。点击「一键补货」会将符合顾客需求和预算的商品摆到柜台；检查后使用游戏原有的出售按钮手动成交。

不自动出售、抹零、递归搜索内层容器或拆分合并堆叠。柜台已有商品会占用顾客预算；无限预算顾客不会自动补货。选中的交易区及包含它的容器不会被当作商品。空间不足或游戏规则拒绝会跳过物品。

已通过编译，尚未在游戏中验证界面与交互。首次使用前请备份存档，并先用低价值物品测试。
