# 地下交易材料单 1.1.4

正式版内置 ModLoader 模组。垃圾桶正面贴有一张像素风格的纸质清单，点击后打开复用原版图文的模组交易窗口，在每一行右侧增加“交换”按钮。保留原版材料、奖励图像和促销显示规则，点击“交换”补齐一份材料。夜间奖励和清洁仍由原版游戏处理，需要启用清洁服务。

纸张挂在垃圾桶本身的图像节点上，随其位置和缩放变化；纸张节点使用空的 `TreeNodeRender` 接管游戏物品射线，因此点击纸张只会打开窗口，不会触发垃圾桶本身的双击、拖动或物品提示；纸张之外的区域保持原版交互。

- 纸张、交易窗口和暗格确认统一旧玫瑰色纸面与梅紫色印刷；行内复用原版图文，按钮保留原生样式。
- 检索主库存、台面、前台、展示柜、暗格、文件、装备及雇员库存和自有内层容器，排除机器内部、顾客财物、垃圾桶与已售区域，并去重。
- 存档解锁黑市兑换后才显示纸张；切换未解锁存档后隐藏并关闭清单。
- 悬停复用 RenderHandler.SetHighlightColor 的 White/Grid 原版素材平铺，关闭普通 Button 额外变色。
- 垃圾桶已备齐时禁止重复投放；已有部分材料时只补缺额。
- 优先损坏模组，再使用库存中的其他模组；机器内部物品不作为材料。
- 滤芯按剩余耐久从低到高选择，耗尽的优先。
- 非空走私者暗格弹出确认；取消不投放，确认时重新检查库存、促销和空间。
- 不取固定、锁定或不属于玩家的物品；带内容的其它容器不参与交易，避免内容物丢失。
- 按游戏交易优先级（含促销）检查材料争用，保证投入的材料正好被当晚结算消耗。
- 材料逐个拆堆、预检格位、失败逆序回滚；投放后重新模拟确认目标交易仍能成交。
- 纸质入口在 1.0.1 的基础上升级为“材料单”外观，比例调整为垃圾桶背景的 0.40。

安装包在 `package` 目录，包含 DLL、manifest.xml 和 preview.png。沿用现有 reflection-external 权限，本轮未增加权限。封面来源及提示词见 ARTWORK.md，构建时不再覆盖为旧占位图。
