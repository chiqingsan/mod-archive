# 地下交易助手实现计划

## 目标

垃圾桶正面贴一张可点击的纸质清单；打开原版图文交易窗口，在每项右侧增加交换按钮。按钮只把一份所需材料放入垃圾桶，奖励仍由原版夜间结算发放。

## 实施顺序与状态

1. 已完成：结算顺序模拟、材料补齐计划、重复投放与材料冲突检查。
2. 已完成：正式版接口适配。读取当前常驻和启用促销交易；筛选库存材料；损坏模组与低耐久滤芯优先；识别非空暗格。
3. 已完成：逐单位拆堆、垃圾桶独立格位预检、搬运失败逆序恢复、投放后的匹配核对。移动使用游戏原生 `GetSplitItem` + `TryInventorySlot` + `AcceptUnchecked` 原子序列，不再手工克隆堆。
4. 已完成：垃圾桶正面的像素纸张入口、复用原版交易图文窗口、按钮状态和悬浮原因、独立模态暗格确认；确认时重新生成计划。常驻七行按原版 `PermaSection` 子级顺序绑定，促销按 `ExchangeUIManager.promotionalSection` 子级里非空 `ExchangeElement.identifier` 绑定，不再把常驻行误当促销行隐藏（1.0.1 的空白面板问题）。
5. 已完成（1.1.1）：原生窗口打开检测（原版交易指令物品打开时也会挂按钮）、原生 `CountTMP` 隐藏并由按钮下小字替代、按钮与面板拖动隔离、刷新按内容签名降频（1 秒采样、仅内容变化时重算）、纸张尺寸调整为垃圾桶背景的 0.40。
6. 已完成：IMod 生命周期、manifest（1.1.1）、安装包、核心与搬运集成测试。待游戏内验收原生窗口位置、字体和完整跨夜结算。

## 验收

- 六个滤芯只投入一次交易需要的三个；已有部分材料只补缺额，已有完整材料禁用按钮。
- 有耗尽滤芯时先用耗尽滤芯；模组先用损坏模组，机器内模组不参与。
- 非空暗格必须确认；取消不移动任何材料，确认后重新检查状态。
- 高优先级交易不得使投入的材料被另一笔交易占用；材料不足、交易未解锁、交易受阻和垃圾桶空间不足均禁用。
- 搬运中途失败不能遗失物品；促销随存档读取，换周后更新。
- 常驻交易七行在窗口内始终可见，按钮位于原生“每晚一次”位置，不遮挡材料与奖励图标。
