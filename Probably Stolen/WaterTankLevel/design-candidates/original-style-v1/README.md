# 原版风格储水罐素材

这是基于游戏 0.46D 原版 `water_jug` 制作的 64×64 物品素材候选。桶身保留原版轮廓、颜色与透明度，只在瓶盖下方增加一个 3×2 像素的小标记；液体层直接使用原版 `xl` 对应水位与颜色帧，未缩放或重绘。

`Textures/Items` 含桶身和蓝、红、暗色各五档水位，共 16 张 PNG，文件名与当前 WaterTankLevel 模组的资源加载代码匹配。空桶不绘制液体层。该方案不单独叠加原版水面高光层。

`original-comparison.png` 左侧为原版桶身，右侧为本方案；`water-levels-preview.png` 从左到右为空、10、25、50、75、100 档，按示例颜色着色预览。

本目录是素材候选，不是完整模组；未部署，尚未经过游戏内验证。请勿把本目录直接当作模组安装。
