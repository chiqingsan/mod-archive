# 更好的库存排序

更好的库存排序工具（v1.1.0）。DLL 文件名保持为英文 `SmartInventoryArrange.dll`。

- 优先排列大件、容器、机器和储藏类物品。
- 相同物品尽量连续摆放。
- 相同类型尽量集中在相邻区域。
- 通过全局布局搜索减少空洞、狭窄碎片和类别交错。
- “保留容器排列”会将有内容窗口的容器以及电源块作为固定障碍，只移动其他物品。
- 应用前后校验库存快照；检测到库存被外部改变时会取消操作，避免覆盖玩家的新操作。

## 使用方式

打开库存或展示柜后，在库存网格的空白位置打开排序菜单，再选择“智能排列”或“保留容器排列”。右键点击容器物品本身只会打开游戏原有的物品菜单；整理按钮位于排序菜单中。

## 权限说明

该版本需要文件读写权限来保存诊断快照，并需要反射权限来访问正式版排序窗口的内部字段。这两项权限由正式版 Mod 审核界面显示并确认。

设置项位于游戏的 Mod 设置中，可控制保留容器模式是否固定容器。
