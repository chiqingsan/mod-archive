# 回来吧, 水商!(水商数值回归) 1.1.0

适配本机当前正式版原生模组加载器。进入游戏的模组设置，可独立开启或关闭 12 项功能，默认全部开启；设置修改时生效。

- 集水器：产量、耗电、多台产量削减、价值。
- 过滤：过滤微生物、滤芯残留下限、紫外线灯安装。
- 净水器：使用游戏新版净化算法；纯度 96% 及以上时污浊度倍率为 1.5，品质加成达到 150% 时最高纯度为 100%，均可单独关闭。
- 海德拉：耐久上限、等比例去除杂质。
- 水质：Demo 新水杂质配方。

已拥有集水器调整价值时会保存原值，关闭该设置后恢复；0.1.1 已经改变且未记录原值的旧物品无法可靠自动还原。关闭海德拉耐久上限时，如果当前或伪装耐久超过 300，则暂时保留 400 上限避免截断耐久；耐久降至 300 或以下时恢复。关闭 UV 安装设置不会强行移除已经装入壶内的灯。关闭杂质配方不会重新改变已生成的水。

复制 manifest.xml 与 WaterMerchant.dll 到游戏目录 Mods/WaterMerchant，退出并重启游戏加载新版本。新版本可能需要在模组列表重新审核启用。封面.png 为 1672×941，约 1.777:1。

详细数值见《对照与验证.md》。构建和静态检查通过，尚未验证实际游戏内设置界面、存档及各开关组合。测试前建议备份存档。
